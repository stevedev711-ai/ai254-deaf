Lecture captions and classroom signing for Deaf and hard-of-hearing students

An Android app that captions the lecturer in English or Swahili without internet, and a sensor glove that turns a small set of Kenyan Sign Language (KSL) signs into spoken phrases, only after the student confirms them.

How it works

Captions

The phone listens to the lecturer and transcribes speech with whisper.cpp on the device, in English or Swahili. Audio is processed in four-second chunks and never leaves the phone. The app has no internet permission.

The glove

An ESP32 board reads five flex sensors (one per finger) and an MPU-6050 motion sensor 20 times a second and sends them to the phone over Bluetooth Low Energy.

Sign reading

When the student taps Read one sign, the app collects two seconds of readings and runs a small TensorFlow Lite model. Unclear or unsupported signs are rejected, and the result is spoken with an offline voice only when the student confirms it.

Training

Teams record repeated examples from several consenting signers, review the vocabulary with KSL users, and test on signers the model has never seen before using it in class.

Get it running

  1. Install the app. Download the APK above on an Android 13+ phone and allow installing from your browser when Android asks.
  2. Add a speech model. Download a multilingual whisper.cpp model (Small is a good start) from the official model list, then use Import Whisper model in the app.
  3. Add an offline voice. Install English text-to-speech data in Android settings and check it works in airplane mode.
  4. Build and train the glove. Follow the wiring table and training steps in the README, then import ksl.tflite and labels.txt into the app.

What it can't do yet

  • The glove reads finger bends and hand movement only. It misses facial expressions and the other hand, so it can't translate KSL in general — only a small, reviewed classroom vocabulary.
  • Caption speed depends on the phone. Measure the delay on the actual device before relying on it in a lecture.
  • The reference glove's Bluetooth link is unencrypted. Add authenticated pairing before using it outside a controlled setting.
